# Multimodal Attendance & Engagement Agent
Run: `pip install -r requirements.txt && streamlit run app.py`. Deploy: push this folder to GitHub, point Streamlit Community Cloud at `app.py`.
Modules: `vision.py` (detect/track/attendance), `audio.py` (VAD + classes), `fusion.py` (rule-based index), `advisor.py` (suggestions), `demo.py` (synthetic session).
